Brand and style guide

A small, serious lab. Free, open-source software for private computing. The design is plain on purpose: readable, fast, stable, and owned by the people who run it.

This guide governs Autobot, Invincible and the Sovware studio site. Autobot is the first site built on it.

Position

Sovware is an independent software lab. We build the fundamentals: local runtimes, network policy, records, and the interfaces around them. The work is public, the releases are signed, and the claims are checkable.

Voice

Write like a maintainer, not a marketer. Short declarative sentences. Concrete nouns. Numbers where they exist. State the limit as plainly as the feature.

Use

  • Autobot runs chat, agents, images and voice on the device.
  • Offline by default. Cloud providers are optional.
  • Apache-2.0. Source available.
  • The Snapdragon paths are built for the 8 Elite Gen 5 and have not yet been run on it.
  • Every answer carries a privacy receipt.

Avoid

  • Experience the future of private AI.
  • Blazing-fast, seamless, revolutionary, empower, unleash.
  • Open-source revolution.
  • Trust us.
  • Exclamation marks. Superlatives. Claims without a link.
Rule of thumb: if a sentence would fit in a funding announcement, cut it. If it would fit in a README, keep it.

Rules

Do

  • Lead with what the software does.
  • Show the version, license, platform and date.
  • Link to the source, the release, the checksum.
  • State limitations in the same type size as features.
  • Keep every page readable without JavaScript.
  • Use the smallest number of words that is still precise.

Do not

  • Add a hero illustration or an animation.
  • Use cards, shadows, gradients or decorative numbers.
  • Write a manifesto on a product page.
  • Hide the caveats in a footnote.
  • Load anything from a third party.
  • Change the accent colour to make a page “pop”.

Implementation

  • Output: static HTML and one CSS file. No client JavaScript.
  • Fonts: self-hosted Inter and EB Garamond, WOFF2, Latin subset, preloaded.
  • Requests: none to a third party. No analytics, cookies or fingerprinting.
  • Delivery: Cloudflare Workers Static Assets, immutable caching for fonts and CSS.
  • Accessibility: WCAG AA contrast, 16 px body, visible focus, skip link, semantic headings.

Review status

This is version 1 of the brand guide. Autobot is the first implementation. Do not start Invincible or Sovware until Autobot is confirmed.
